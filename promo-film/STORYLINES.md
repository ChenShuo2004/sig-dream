# Storylines — sig-dream Open-Source Launch Film

## 1. Storyline A — "One Canvas Replaces Six Tabs" (Recommended & Selected)

- **Device × Form**: *Life before and after* × *Object-to-object beat chain*
- **What the viewer sees and feels**: Six cramped dark browser/terminal panes (`postgres connection refused`, `redis ECONNREFUSED`, scattered AI image/video tabs) churn in cold monochrome tension until a decisive cursor click collapses them into the `sig-dream` Möbius mark, opening a warm obsidian infinite canvas where a single character node branches live into style variants, storyboards, and three production studios. The viewer feels instant relief ("no database, no login, everything stays local on one canvas") followed by creative momentum.
- **First two seconds**: Frame 0 opens on a high-contrast 6-pane split grid of fragmented AI tabs and failed Docker Postgres logs with the dead-still bilingual headline `6 个网页切来切去？还要先配数据库？` (`6 TABS · POSTGRES · REDIS · JUST FOR ONE AI CLIP?`).
- **Beats**: `hook (6-tab & DB pain) → shatter into Möbius mark → zero-DB 30s API Key setup → infinite canvas live remix & full-board pull-back payoff → 3-studio + 1,740+ prompt beat trilogy → MIT open-source end card`
- **Look**: Warm obsidian ground (`#0e0d0c`) with subtle `18px` dot matrix (`rgba(245,245,244,0.12)`), crisp stone-white ink (`#fafaf9`), monochrome black/white Möbius mark, and rationed warm terracotta accent (`#e3a785`) taken directly from `sig-dream` Home (`src/pages/home/index.tsx`).
- **Sound**: 120 BPM minimal dark electronic pulse (filtered tense intro in Bars 1–2, clean sub-kick + 16th shaker groove at `t=4.0s`, rising into a bright minor-9th synth drop at `t=16.0s` payoff), paired with exact UI clicks, typing bursts, whooshes, and sub impacts.

## 2. Storyline B — "Pull Back From the Finished Film"

- **Device × Form**: *The result first* × *Endless zoom out*
- **What the viewer sees and feels**: Opens full-bleed on a finished sci-fi storyboard sequence playing inside a node, then pulls back step by step: from the video node, to the 4 style-exploration nodes feeding it, to the 100k-word Script Studio that locked its palette, and finally to the local desktop window running with zero backend.
- **First two seconds**: Full-screen clay/cyberpunk character shot with a live playhead bar, suddenly zooming back at `t=1.4s` to reveal Bezier wires feeding into the frame.
- **Beats**: `finished shot → pull back to style wires → pull back to full infinite canvas → reveal Script/Replication/Replacement studios → reveal Zero-DB local config → MIT end card`
- **Look**: Pure matte charcoal `#111111` stage, architectural 1px hairlines, `Inter` + `PingFang SC` heavy display, emerald status accent.
- **Sound**: 124 BPM reverse-swell opener into steady four-on-the-floor synth-tech groove with camera-zoom air sweeps.

## 3. Storyline C — "30-Second Stopwatch Challenge" (Bold)

- **Device × Form**: *A number lands* × *Split screen to one*
- **What the viewer sees and feels**: A giant monospace `00:30.00` countdown splits the screen: on the left, `docker compose` is still pulling Postgres layers; on the right, `sig-dream` opens from `.dmg`, pastes an API Key at `00:22`, remixes a character on the infinite canvas at `00:11`, and exports a storyboard pack with time to spare before taking over 100% of the frame.
- **First two seconds**: Giant `30.0s` timer slams onto frame 0 splitting `Postgres Setup` vs `sig-dream.dmg`.
- **Beats**: `30s split-screen start → API Key pasted in 8s → canvas node remix & prompt library in 12s → left pane eliminated → full-screen studio showcase → MIT end card`
- **Look**: Stark monochrome black-and-white `#09090b` / `#fafafa` editorial grid with `JetBrains Mono` giant numerals.
- **Sound**: Sharp 120 BPM mechanical clock-tick percussion morphing into a heavy industrial bassline when the right pane takes over full screen.
