# Two.js · 2D 矢量图形与创意动效

> 官方仓库：https://github.com/jonobr1/two.js

## 适用场景
- 品牌片头几何演进、动态背景纹理、音频驱动波形与可无损缩放的 2D 矢量图形动画。

## 核心实践
1. **分组层级管理**：用 `two.makeGroup()` 组织复合图形，统一驱动位移、旋转与缩放。
2. **路径锚点变形**：直接操作 `path.vertices` 实现有机液态波动、线条呼吸与形状渐变。
