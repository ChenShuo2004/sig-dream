# Ola · 数值平滑变动与惯性插值

> 官方仓库：https://github.com/franciscop/ola

## 适用场景
- 数据大屏数字滚动、指标卡片平滑跳动、相机跟随与鼠标平滑阻尼追踪。

## 核心实践
1. **声明式平滑状态**：`const pos = Ola({ x: 0, y: 0 }, 300)`，更新目标值时自动按缓动曲线连续逼近，无需手动取消旧动画。
2. **与帧循环结合**：在每帧读取当前插值渲染到 Canvas / SVG / DOM，保证指标数值跳变自然不闪烁。
