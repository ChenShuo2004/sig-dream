# 01 系统架构

## 逻辑架构

```
浏览器 / 未来桌面壳 WebView
        │
        ▼
Next.js ── rewrite ──► /api-proxy/* ──► FastAPI（ECS）
        │                                  │
        │                                  ├── PostgreSQL
        │                                  ├── nas_jobs / sync_operations
        │                                  └── 鉴权、票据、元数据、操作日志
        ▼
NAS Worker（文件机）◄── poll/complete ──► FastAPI
        │
        ▼
download_server：/download、/health、LAN 上传等
        │
        └── 大文件优先 LAN/WAN；兜底 prepare_download → ECS download_cache
```

## 组件职责

| 组件 | 职责 |
|------|------|
| **Next.js** | UI；**`fetch("/api-proxy/...")`**；**`localStorage` + Cookie**（见 **`frontend/lib/auth.ts`**） |
| **FastAPI** | JWT、**`ensure_permission`**、业务 CRUD、下载/上传票据、**`nas_jobs`**、**`record_operation_log`** |
| **PostgreSQL** | 全量业务与审计 |
| **NAS Worker** | **`store_original`**、**`generate_derivatives`**（缩略图 + 预览 MP4 等）、**`prepare_download`**、回收站移动/恢复 |
| **download_server** | 票据校验后读盘；**`report`**；与浏览器 **CORS** 协调 |

## 大文件与 ECS 边界

- **`download-route`** 返回 **`recommended_order`**：`lan` → `wan` → `ecs_fallback`。
- **ECS**：鉴权、票据、元数据、任务编排、兜底缓存；**不作为**日常大文件主路径。

## 维护模式

**`maintenance_guard`**（**`main.py`**）：维护开启时，除白名单外 **POST/PUT/PATCH/DELETE** 返回 **423**。白名单含 **`/auth/`**、**`/nas-jobs/`**（含 **`poll`**）。**教程进度 POST** 不在白名单。

## 异常与操作日志

- 部分 **401/403/5xx** → **`record_operation_log_safe`**。
- 未捕获异常 → **`record_operation_log_safe`**。
- 业务仍以各路由 **`record_operation_log`** 为主。
