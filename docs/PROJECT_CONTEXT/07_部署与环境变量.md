# 07 部署与环境变量

> 敏感值写作 **`<REDACTED>`**。发布流程可参考仓库 **`2026年4月26日更新发布流程.md`**、**`release-new-version.bat`**、**`deploy-oneclick.ps1`**。

## 前端

| 变量 | 说明 |
|------|------|
| **`NEXT_PUBLIC_API_BASE_URL`** | 后端根 URL（无 `/api` 后缀），供 **`next.config.ts`** 将 **`/api-proxy/:path*`** rewrite 到后端 |

构建：`cd frontend && npm ci && npm run build`；运行：**`npm run start`**（或平台托管）。

现网公网入口：**`https://your.domain.example.com`**（ECS Nginx **80/443** 反代本机 Next **`:3000`**；证书 **Let’s Encrypt**）。API 仍由 Next **`/api-proxy`** 转到 **`127.0.0.1:8000`**。

## 后端（`backend/app/core/config.py`）

自环境变量或 **`backend/.env`** 读取，主要包括：

| 字段 | 用途 |
|------|------|
| **`database_url`** | PostgreSQL（**`<REDACTED>`**） |
| **`nas_client_token`** | **`X-NAS-Client-Token`** |
| **`nas_base_url`** | 服务端自调用基准 |
| **`nas_mount_root`** | ECS 校验 NAS 相对路径时的挂载根 |
| **`lan_download_base_url`** / **`lan_upload_base_url`** | 单节点 LAN 默认根 |
| **`public_download_base_url`** / **`public_upload_base_url`** | WAN 根 |
| **`default_storage_pool_id`** | 与 **`materials.storage_pool_id`**、节点 **`pool_id`** 对齐 |
| **`file_service_node_stale_seconds`** | 节点心跳过期秒数 |
| **`file_service_infer_public_from_ingress`** | 从入站推断公网基址 |
| **`file_service_poll_bootstrap_registry`** | poll 时自注册节点 |
| **`file_service_bootstrap_node_id`** | 引导节点 ID |
| **`download_ticket_secret`** | HMAC 密钥 |
| **`download_ticket_ttl_seconds`** / **`upload_ticket_ttl_seconds`** / **`download_cache_ttl_seconds`** | TTL |
| **`app_build_version`** | 可选；否则 **`/health`** 可能回退 git short hash |

## NAS Worker（`nas-client/worker.py`）

| 变量 | 说明 |
|------|------|
| **`NAS_API_BASE_URL`** | 后端 API 根 |
| **`NAS_CLIENT_TOKEN`** | 与后端一致 |
| **`NAS_MOUNT_ROOT`** | 与库内 **`file_path`** 拼接 |
| **`NAS_POLL_INTERVAL_SECONDS`** / **`NAS_HTTP_TIMEOUT_SECONDS`** | 轮询与 HTTP 超时 |
| **`NAS_PREPARE_UPLOAD_TIMEOUT_SECONDS`** | **`prepare_download`** 上传 ECS 超时 |
| **`NAS_DOWNLOAD_CHUNK_SIZE_BYTES`** | 拉 **`/source`** 分块 |
| **`NAS_WORKER_CONCURRENCY`** | 并发线程数 |
| **`NAS_POLL_JOB_TYPES`** / **`NAS_EXCLUDE_JOB_TYPES`** | 任务类型过滤 |
| **`NAS_FFMPEG_BIN`** / **`NAS_FFPROBE_BIN`** | ffmpeg/ffprobe 路径 |

**`local-env.example.bat`** 等：占位 **`NAS_CLIENT_TOKEN`**、SSH、**`DEPLOY_*`**；勿提交真实密钥。
