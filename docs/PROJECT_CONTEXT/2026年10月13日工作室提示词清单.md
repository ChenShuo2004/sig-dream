# 工作室提示词清单（剧本 / 复刻 / 替换）

画布顶栏「画布模式」下的三个工作室复刻自 SHUO Canvas（`D:\asuo画布\AI CanvasPro\SHUO Canvas\resources\webapp`）。凡是能从客户端拿到的调用模型提示词，都**逐字照搬**原文；复刻工作室在 SHUO 服务器端执行的几步（看原片、ASR、切分、分镜、审核）拿不到原文，按可见的输入输出格式自己编写。

## 提取流水线

脚本位于 `tools/shuo-prompt-extract/`，按顺序执行：

| 步骤 | 命令 | 产物 |
| --- | --- | --- |
| 导出常量 | `node extract.mjs "<webapp 目录>"` | `out/shuo-prompts.json`（把模块复制到临时目录，给每个文件补一行 `export {顶层绑定}`，再在 Node 里导入，读出运行时的真实值） |
| 内部字面量 | `node harvest-literals.mjs "%TEMP%\shuo_deob\out"` | `out/shuo-literal-prompts.json`（从还原后的源码里收集纯字面量 `[...].join("\n")`，如大纲三段 system prompt） |
| 构建函数样例 | `node capture.mjs` | `out/shuo-prompt-samples.json`（用演示数据调用 `build*Prompt` / `reviewStoryStage` 等函数，截获完整 user 载荷） |
| 生成 TS | `node build-ts.mjs` | `canvas-app/web/src/studios/prompts/*.generated.ts` |

`build-ts.mjs` 会用两组不同参数（集数、风格、单片最大秒数）各调用一次构建函数，差异处替换为占位符，其余文字保持原文。若有无法识别的差异位置，会打印 `unresolved`。`out/` 不入库，入库的产物是生成的 TS。

占位符：`{{episodeCount}}`、`{{episodeMin}}`（\(\lceil 集数 \times 0.9 \rceil\)）、`{{style}}`、`{{clipMaxSeconds}}`、`{{episodeTitle}}`；数字位置写成 `{{name:number}}`。

## 剧本工作室（`script.generated.ts`）

- `SCRIPT_SYSTEM_PROMPTS`：摘要、长文摘录、大纲（一次完成 / 骨架 / 批量细化 / JSON 契约修复）、分集剧本（剧情 / 自然内容 / 修复 / 内容修订）、素材提取（提取 / 格式修复 / 来源修复）、分镜拆解（`split["seedance-2.0" | "seedance-2.5"]`，紧凑格式）、分镜格式校验、审片员、片段 AI 调整。
- `SCRIPT_TEMPLATES`：各阶段 user 载荷模板（`task`、`schemaVersion`、`requirements`、`outputSchema` 等），调用时补入当期输入：
  - `summary[<generate|upload|rewrite>_<plot|narration>_<style|plain>]`：补 `input`。
  - `outline[scriptMode]` / `outlineBatch[scriptMode]`：补 `storySummary` 或批次上下文。
  - `episodeScript[scriptMode]`：补 `storySummary`、`originalCreative`、`currentEpisode`、`continuity`。
  - `assetExtraction[style|plain]`：`prefix + JSON(payload + project + visualDirection) + suffix`。
  - `split[<promptMode>_<scriptMode>]`：补 `episodes`，输出紧凑格式 `{"episodes":[{"episodeRef","clips":[{"s","shots":[{"d","v","c","q","o","a"}]}]}]}`。
  - `splitValidationPrompt`、`clipAdjust`、`splitReview`、`splitRepair`。
  - `stageReview[summary|outline|script]`：自动审核（`review_story_stage_content`）与核验修补（`resolve_story_stage_findings`）的 system prompt、`criteria`、`instructions`、`outputSchema`。
- `SCRIPT_PRESETS`：角色立绘前缀、参考图后缀、角色 / 场景素材预设、风格预设、首页示例创意、镜头预设。

## 复刻工作室（`replication.generated.ts`）

- `generationSystemPrompt`：`getReplicationGenerationSystemPrompt()` 的原文。
- `rules`：全部 `REPLICATION_*_RULE` / `_GUIDANCE`（内容、时间线、镜头、语音、朝向、视觉状态、切点等）以及 `SEEDANCE20_REPLICATION_REPAIR_FORMAT_RULE`。
- `videoStyleSummaries`、`videoExecutionConstraints`。
- `textAssetSystemPrompt` 与 `textAssetBatch`：文本素材提取的 system prompt、载荷模板、JSON Schema、温度和 token 上限。
- 看原片 / ASR / 切分 / 分镜生成 / 审核：SHUO 在服务器端执行，按 `flowSource{videoObserved, characters, shots, speech}` 契约自己编写。

## 替换工作室（`replacement.generated.ts`）

- `defaultVideoPrompt`、`manualPromptExample`、`manualModeFormat`、`manualEnhancementTooltip`。
- `enhancementSystemPrompt`：人物替换提示词增强（视觉模型）。
- `characterAssetPromptPresets`、`minimaxH3`（MiniMax / 海螺 H3 的替换与口型预设）。
- 定位提示词 `buildPersonReplacementPositioningPrompt` 是代码按片段拼装的，按还原后的片段原文移植到替换工作室的运行时代码里。
