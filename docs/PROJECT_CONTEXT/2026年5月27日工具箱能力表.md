# 工具箱能力表

> **Web**（`frontend/`）与 **桌面素材助手**（`desktop-client/`）共用本表。  
> 沟通与实现时区分四层：**壳（Surface）**、**可用（Runnable）**、**运行时（Runtime）**、**数据路径（Data path）**。  
> 桌面集成总则见 **`.cursor/rules/desktop_client_integration.mdc`** § 〇。

## 四层定义

| 层 | 含义 | 示例 |
|----|------|------|
| **壳** | 导航/列表是否展示入口 | 两端都有「视频转 GIF」卡片 |
| **可用** | 用户能否完整跑通 | Web / 桌面均可生成（如 `video-to-gif`） |
| **运行时** | 算力在哪 | `browser` / `ecs` / `nas-worker` / `electron-main` |
| **数据路径** | 文件从哪来、结果去哪 | `local-file`（本机 File，仅下载） |

**默认策略（工具箱）：**

- **壳**：Web + 桌面 **一致**（Hash 路由 `#/toolbox/...` 与 Web `/toolbox/...` 一一对应）。
- **可用**：按工具单独配置；桌面不可用时 **灰显 + 同文案**，**不删**入口（策略 **A**）。
- **业务写入**：仍只经 **ECS FastAPI**；纯浏览器小工具 **不上传、不写库** 时 **无 ECS/文件机**。

## 平台与运行时对照

| 你说 | 目录/组件 |
|------|-----------|
| **Web** | `frontend/`，浏览器 |
| **桌面** | `desktop-client/`，Electron |
| **ECS** | `backend/`，鉴权/任务/元数据 |
| **文件机** | `nas-client/` Worker（ffmpeg 等） |
| **本机** | 浏览器或 Electron 主进程，不经业务写库 |

## 工具能力卡：`video-to-gif`

```text
【工具箱 / 工具ID】video-to-gif
【中文名】视频片段转 GIF
【路由】Web: /toolbox/video-to-gif  桌面: #/toolbox/video-to-gif

【壳】Web: 有  桌面: 有
【可用】Web: 是  桌面: 是


【运行时】Web: browser（gifenc / gif.js 等）  桌面: browser（Electron 渲染进程，同源 API）
【数据路径】用户选择本地视频 File；输出 GIF 本机下载；不写库、不上传 ECS

【ECS/文件机】无
【权限】需登录（Web middleware / 桌面登录态）

【业务限制】
- 原视频：不限制大小/时长（可提示「文件过大，加载可能较慢」）
- 截取区间：硬限制 ≤ 15 秒
- 帧数：硬限制 ≤ 150 帧（`floor(片段秒数 × fps)`）；与 fps/时长联动，超限则禁用「生成」并提示（例：15s×10fps=150；若 fps=24 则同长片段需缩短或降 fps）
- 默认：输出宽 = 原视频宽（高等比）；**10 fps**
- 高级（可选）：输出宽最大 **1920 px**（超出则等比缩放到 1920 内）、**fps 最大 24**；超出则禁用「生成」并提示

【UI】
- 顶栏：分组 **工具箱**（在 **标签与日志** 与 **系统管理** 之间）→ `/toolbox`
- 首页：同上位置增加 **工具箱** 类目 + **视频片段转 GIF** 卡片
- 列表 `/toolbox`：卡片网格（含本工具）
- 详情：起止时间、实时片段时长、生成进度、取消
- 超限：「GIF 适合短片段，截取最多 15 秒」

【对齐】桌面 **AppHeader / HomePage / 工具页** 与 Web 布局、文案、路由一致；双端 **可用**
```

## 新增工具流程

1. 在本表 **能力总表** 增一行。  
2. 复制上一节 **工具能力卡** 模板，填完整字段。  
3. 更新 **`06_前端页面与路由.md`** 路由表。  
4. 若出现新口语表述，追加 **`2026年4月30日术语对齐记录.md`**。  
5. 实现时优先 **`frontend/lib/toolbox/registry.ts`**（或等价）单源配置，桌面复用或同步结构。
