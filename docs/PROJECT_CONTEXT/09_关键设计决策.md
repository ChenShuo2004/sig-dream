# 09 关键设计决策

> 与 **`.cursor/rules/project_context.mdc`** 一致处不重复；此处列**易误改**点。

1. **素材集合**：**引用**（`asset_collection_items` → `materials` / `material_files`），**不是** NAS 目录树；**分组**仅组织与权限。
2. **未整理**：**`list_unorganized_materials`** — **`status != "trashed"`** 且（**本库「未整理」标签** **或** **零业务标签**），且 **`library_id` 限定当前库**；**不**用 `material.status` 表示未整理。
3. **未整理应用标签**：**清空 `material_tags` 再写**所选标签；**不**靠改 `status` 表示「已整理」。
4. **标签分类**：按 **素材库域** 读取 **`GET /tags/categories?library=`**（或头 **`X-Asset-Library`**）。汽车库 **`auto`** 仍为 **品牌 → 车型 → 版本** 置顶的十类（与 **`library_service.AUTO_TAG_CATEGORIES`** / 前端 **`tagCategoriesForLibrary("auto")`** 一致）；**个人视频库 `personal_video` 仅为「适用主题 / 系统状态」**，一二级分类走 **`library_taxonomy_nodes`**，**禁止**把心理分类写进汽车十类。库内 **`tags.category`** 为自由字符串（合法值由该库后端列表约束）。**标签手动顺序**：**`tags.sort_order`** 为**库内唯一整数**，并按**该库分类号段**预留；管理页 **`POST /tags/reorder`** 仍传 **`category` + `ordered_tag_ids`**。DDL：**`20260508_0020`**（汽车号段）+ **`20260918_0022`**（改为 `(library_id, sort_order)`）。
5. **「标签替换」**：**`POST /tags/merge`**；**≠** **`PATCH /materials/unorganized/batch-tags`**。
6. **下载顺序**：遵循 **`recommended_order`**；缩略图/预览视频等 **不计入** 正式下载计数的路径勿误加 **`download_count`**（见 **`materials.py`**）。
7. **ECS 边界**：大文件主路径为文件机 HTTP；**`prepare_download`** 为兜底。
8. **派生文件**：缩略图/预览 MP4 由 **NAS Worker** **`generate_derivatives`**（及队列扩展）处理；**`POST .../regenerate-derivatives`** 仅 **`asset.edit_all`**、视频扩展名、**NAS** 存储等条件满足时可排队。
9. **权限**：**`PERMISSION_POINTS`** + **`user_roles`** + **`ensure_permission`**；避免业务写死角色名（超管集中校验除外）。
10. **操作日志**：无全局 HTTP 自动写库；缺口见 **`08`**。
11. **`POST /tags/merge`**：**当前不迁移 `material_tags.tag_id`**，合并后引用一致性需单独策略。
12. **双素材库域（共用管道，隔离语义）**：同一套登录 / NAS / 缩略图预览 / 下载选路 / 权限 / 操作日志；**素材、标签、未整理、上传、集合必须带 `library_id`**，缺省上下文为顶栏当前库（**`X-Asset-Library`** 或 **`?library=`**），**禁止默认全库查询**。**不要**把个人视频字段塞进汽车 `_TAG_CATEGORIES`；**不要**用集合或存储池当第二套库。  
    - **`auto`**：现有品牌/车型/… 十类多标签。  
    - **`personal_video`**：一二级 **分类树**（`library_taxonomy_nodes`）+ **检索词 `keywords`** + **承接句意 `copy_fit`** + **适用主题**标签。  
    - 标签唯一改为 **`(library_id, name)`**；**`sort_order`** 库内唯一；每库各自「未整理」。  
    - 第一期权限仍走现有 **`asset.*` / `tag.*` / `collection.*`**，不加库级授权。  
    - DDL：**`20260918_0022_asset_libraries`**。
