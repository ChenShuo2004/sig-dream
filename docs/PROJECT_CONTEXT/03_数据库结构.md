## 核心业务

| 表名 | 模型 | 说明 |
|------|------|------|
| **asset_libraries** | `AssetLibrary` | 素材库域：`auto` / `personal_video` |
| **library_taxonomy_nodes** | `LibraryTaxonomyNode` | 个人视频库一二级分类树 |
| **materials** | `Material` | `library_id`、`status`、`download_count`、`uploader`、`storage_pool_id`；个人视频另有 `keywords`、`copy_fit`、一二级分类外键 |
| **material_files** | `MaterialFile` | `file_path`、`storage_type`、**`extra_metadata`**（缩略图/预览视频路径与状态等） |
| **material_tags** | `MaterialTag` | 多对多 |
| **tags** | `Tag` | **`(library_id, name)` 唯一**、`category`、`status`、`synonyms`、**库内 `sort_order` 唯一** |
| **asset_usages** | `AssetUsage` | 下载使用记录 |
| **asset_operations** | `AssetOperation` | 资产侧操作（与 `operation_logs` 不同） |
