# 00 项目总览

## 名称与定位

**轻量内容流程平台（Light Content Workflow Platform）**：Web 工作台，覆盖工作流编排、素材上传与入库、标签与未整理治理、**双素材库域（汽车 / 个人视频）隔离**、素材库检索与下载（LAN/WAN/ECS 兜底）、**引用型素材集合**、回收站、系统设置、操作日志、**教程引导与进度**等。现网入口 **`https://your.domain.example.com`**。

## 技术栈（以仓库为准）

| 层级 | 技术 |
|------|------|
| 前端 | **Next.js 15.5**（App Router）、**React 19**、**TypeScript**；**Tailwind CSS 3**；**driver.js** 教程；**@xyflow/react** 工作流画布 |
| 后端 | **FastAPI**、**SQLAlchemy 2**、**PostgreSQL**（**psycopg**）；**Pydantic Settings**（`.env`） |
| 任务 / 文件机 | **`nas-client/worker.py`** 轮询 **`GET /nas-jobs/poll`**；**`nas-client/download_server.py`**；**`nas-client/lan_uploader.py`** 等 |
| 迁移 | **Alembic**（**`backend/alembic/versions/`**，当前链末端 **`20260918_0022`**） |
