# 05 核心业务流程

> 密钥与连接串文档写作 **`<REDACTED>`**。

## 1. 上传入库

1. **`POST /uploads/init`** → **`upload_sessions`**。
2. 分片 **`POST .../chunks/{index}`**。
3. **`POST .../complete`** 合并校验。
4. **`POST .../ingest`**：建 **`materials`**（常 **`nas_syncing`**）、**`material_files`**、**`material_tags`**（无有效标签则挂系统 **「未整理」**）；**`store_original`** **`nas_jobs`**。
5. Worker 落 NAS；**`complete_job`** → **`available`**（视分支）→ **`enqueue_generate_derivatives_if_applicable`**（缩略图 + 适用时的预览视频等）。
6. **`uploads.py`** **`record_operation_log`**。

## 2. 未整理打标签

1. **`list_unorganized_materials`**：**`status != "trashed"`** 且（**本库「未整理」标签** **或** **零业务标签**），且限定当前 **`library_id`**。
2. **`PATCH /materials/unorganized/batch-tags`**：**删除该素材全部 `material_tags`** 再写入所选标签；**不**用改 **`material.status`** 表示整理完成。
3. **`POST /materials/batch-mark-unorganized`**：追加「未整理」。
4. 对应 **`record_operation_log`**。

## 3. 素材库查询

1. **`GET /materials`**（**`asset.view`**）；默认列表常仅 **`available`**（见 **`material_service`**）。
2. 筛选：**`keyword`**（标题/关键词/承接句意/分类名）、**`tag_ids_all`**、**`tag_match_mode`**、**`status`**、**`quick_view`**、**`primary_taxonomy_id`**、**`secondary_taxonomy_id`**、**`include_all`**（需 **`asset.edit_all`**）等；**始终带库上下文**。
3. **`serialize_material`** 返回。

## 4. 下载 LAN / WAN / ECS

1. **`POST .../download-route`** → **`ticket`**、基址、**`recommended_order`**。
2. 前端 LAN/WAN **`/health`** → 打开 **`/download?ticket=...`**。
3. 失败：**`download-prepare`** → Worker **`prepare_download`** → **`GET /materials/download-cache/{job_id}`**。
4. 缩略图/预览等 **不计次** 路径勿误计 **`download_count`**。

## 5. 缩略图与预览视频

1. **`generate_derivatives`** 由 Worker 执行；回写 **`extra_metadata`**（**`thumbnail_path`**、**`preview_video_path`** / **`preview_video_status`** 等）。
2. **`GET .../thumbnail-url`**：LAN 票或 ECS 缓存/pending。
3. **`GET .../preview-video-url`**：浏览器可播 **H.264 预览 MP4**（**`scope: preview_video`** 票据）；**不计入下载次数**；依赖 **`preview_video_path`** 就绪。
4. **`POST .../regenerate-derivatives`**：**`asset.edit_all`**，仅允许的视频扩展名且文件在 **NAS**；若已有 pending/running 同类任务可 **skipped**。

## 6. 标签替换（合并）

1. **`POST /tags/merge`**（**`tag.merge`**）。
2. **`merge_tag`** 更新标签行状态与同义词等。
3. **≠** **`batch-tags`**（素材侧替换标签行）。
4. **缺口**：**不自动迁移 `material_tags.tag_id`**。

## 7. 回收站

1. **`DELETE /materials/{id}`** → 软删 + **`move_to_trash`**。
2. **`GET /materials?status=trashed,trash_pending`** 或 **`/trash`**。
3. **`POST .../restore`**、**`DELETE .../permanent`**。
4. Worker 物理移动；**`record_operation_log`**。

## 8. 素材集合（引用）

1. 分组/集合 CRUD（**`/collections`**）。
2. **`POST .../items`** 或 **`POST /materials/{id}/collect`** 写 **`asset_collection_items`**。
3. 集合内浏览下载仍走 **`/materials`** 票据与选路。
