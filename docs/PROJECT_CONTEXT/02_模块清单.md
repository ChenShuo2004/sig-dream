# 02 模块清单

> 每模块：**定位** | **页面** | **核心接口** | **数据库表** | **权限点** | **操作日志**  
> 权限点定义：**`backend/app/services/settings_service.py`** → **`PERMISSION_POINTS`**。

---

## 系统设置

| 项 | 内容 |
|------|------|
| **定位** | 超管：用户、角色-权限矩阵、系统 JSON 配置 |
| **页面** | `/settings` |
| **核心接口** | `GET/PATCH /settings`；`GET/POST/PATCH/DELETE /settings/users*`；`PATCH /settings/users/{id}/roles`；`GET/PATCH /settings/roles/{id}/permissions`；`GET /settings/permissions`；`GET/POST/DELETE /settings/user-groups*` |
| **表** | `users`、`roles`、`permissions`、`role_permissions`、`user_roles`、`system_configs` |
| **权限** | **`_require_super_admin`**；**`user.manage`**、**`role.manage`**、**`system.setting.manage`** |
| **日志** | **`settings.py`** 写操作 **`record_operation_log`** |

---

## 角色权限

| 项 | 内容 |
|------|------|
| **定位** | 权限为字符串 code；**`POST /auth/login`** / **`GET /auth/me`** 返回 **`permissions`**；以 **`user_roles`** 为准 |
| **页面** | 嵌入 `/settings` |
| **核心接口** | 同系统设置 + `/auth/*` |
| **表** | `roles`、`permissions`、`role_permissions`、`user_roles` |
| **权限** | 全量见 **`PERMISSION_POINTS`** |
| **日志** | 角色权限变更在 **`settings`** |

---

## 操作日志

| 项 | 内容 |
|------|------|
| **定位** | 审计查询；非每个 HTTP 自动落库 |
| **页面** | `/operations`（**`log.view`**） |
| **核心接口** | `GET /operation-logs`、`GET /operation-logs/enums`、`GET /operation-logs/{user_id}` |
| **表** | `operation_logs` |
| **权限** | **`log.view`** |
| **日志** | 本模块查询；**`main.py`** 对部分异常 **`record_operation_log_safe`** |

---

## 标签管理

| 项 | 内容 |
|------|------|
| **定位** | 标签 CRUD、合并、审核、偏好；分类 **`GET /tags/categories`**（**按素材库域**；汽车十类仅 `auto`） |
| **页面** | `/tags`、`/tag-requests` |
| **核心接口** | `GET/POST /tags`、`GET /tags/active`、`GET /tags/categories`；`PATCH .../deactivate|activate|trash`；**`POST /tags/merge`**；`POST /tags/apply`；`PATCH /tags/{id}/review`；`DELETE .../permanent`；`GET/PUT /tags/preferences`；个人视频库分类树 **`/libraries/{code}/taxonomy`** |
| **表** | `tags`、`material_tags`、`user_tag_preferences`、`asset_libraries`、`library_taxonomy_nodes` |
| **权限** | **`tag.*`** |
| **日志** | **`tags.py`** / **`libraries.py`** 写操作已记 |

## 素材库域

| 项 | 内容 |
|------|------|
| **定位** | 同平台两套语义库：汽车 / 个人视频；列表、标签、未整理、上传、集合按 **`library_id` 隔离** |
| **页面** | 顶栏切换；`/materials`、`/unorganized`、`/materials/upload`、`/collections`、`/tags` 等读当前库 |
| **核心接口** | **`GET /libraries`**；**`GET/POST/PATCH/DELETE /libraries/{code}/taxonomy`**；业务接口头 **`X-Asset-Library`** 或 **`?library=`** |
| **表** | `asset_libraries`、`library_taxonomy_nodes`；业务表挂 `library_id` |
| **权限** | 第一期沿用 **`asset.*` / `tag.*` / `collection.*`** |
| **日志** | 分类树写操作记库 |

## NAS Worker / 文件机

| 项 | 内容 |
|------|------|
| **定位** | **`nas-client/worker.py`**；**`download_server.py`** |
| **页面** | 无 |
| **核心接口** | **`GET /nas-jobs/poll`**；**`POST .../complete|fail|start`**；**`GET .../source`**；心跳；**`/nas-jobs/sync/*`**；DB 导入导出 |
