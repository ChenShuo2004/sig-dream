# 06 前端页面与路由

> **Next.js App Router**（**`frontend/app/`**）。API：**同源 `fetch("/api-proxy/...")`**。

## 鉴权

| 机制 | 说明 |
|------|------|
| **`middleware.ts`** | 除 **`/`**、**`/login`** 外，无 Cookie **`lcp_auth_token`** → 重定向 **`/login?auth=required&redirect=...`** |
| **`pathname.startsWith("/api")`** | 放行 **`/api-proxy`**（前缀匹配 **`/api`**） |
| **`lib/auth.ts`** | **`lcp_auth_session`**（localStorage）+ 登录写 **`lcp_auth_token`**（`SameSite=Lax`，`Path=/`，`Max-Age=604800`） |

## 顶栏

**`AppHeader.tsx`**：画布（`/canvas`，无下拉）、素材（含 **`/collections`** 需 **`collection.view`**）、标签、**工具箱**（在 **标签与日志** 与 **系统管理** 之间）、系统、意见、教程等。顶栏 **素材库切换**（汽车 / 个人视频）写入 **`lcp_asset_library`**，素材中心各页请求带 **`X-Asset-Library`**。
