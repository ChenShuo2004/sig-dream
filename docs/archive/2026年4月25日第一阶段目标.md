## 当前总目标（V1）

先把 `materials` 模块做稳并跑通最小闭环，再让工作流节点调用材料能力。

最小闭环：

```text
登录
→ 上传视频
→ 选择标签
→ 分片上传
→ 入库
→ 生成缩略图
→ 列表搜索
→ 下载
→ 记录下载日志
→ 删除进入回收站
→ 管理员恢复
```

## 修正后的阶段顺序（必须按序推进）

## 阶段 1：项目骨架

验收：

- Next.js 能启动
- FastAPI 能启动
- PostgreSQL 能连接
- Alembic 能迁移
- 基础目录结构完成

## 阶段 2：用户与权限

验收：

- 能登录
- 能识别角色等级
- 能识别 `access_context`
- 公网删除类 API 被禁止

## 阶段 3：标签体系

验收：

- 6 大标签分类初始化
- 普通成员可申请标签
- 素材管理员可审核标签
- 标签可停用、合并

## 阶段 4：分片上传

验收：

- 支持初始化上传
- 支持上传分片
- 支持查询已上传分片
- 支持断点续传
- 支持完成合并
- 支持 SHA256 重复检测

## 阶段 5：素材入库

验收：

- 上传后创建 `material_asset`
- 创建 `material_file`
- 写入 `material_tags`
- 生成 `stored_filename`
- 创建 NAS job
- 写操作日志

## 阶段 6：搜索与详情

验收：

- 素材列表可用
- 详情页可用
- 关键词搜索可用
- 标签 all/any 筛选可用

## 阶段 7：下载与使用记录

验收：

- 单文件下载可用
- 批量下载可用
- 每次下载有日志
- `asset_usages` 有记录
- `download_count` 增加

## 阶段 8：回收站

验收：

- 删除进入回收站
- 可恢复
- 可永久删除
- 永久删除需要权限与二次确认
- 公网不能删除

## 阶段 9：NAS Client

验收：

- NAS Client 能拉取任务
- 能写入文件
- 能移动到回收站
- 能恢复
- 能回传任务状态

## 阶段 10：FFmpeg

验收：

- 视频能提取元数据
- 能生成缩略图
- 能生成低清预览
- 缩略图和预览路径写入数据库

## 阶段 11：前端页面整合

验收：

- 普通成员能上传、搜索、下载
- 素材管理员能审核标签、管理回收站
- 超级管理员能修改系统设置
- 公网删除按钮隐藏，后端也禁止
