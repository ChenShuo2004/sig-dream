## 0.1 网址与路径结构（当前环境：`<ECS_PUBLIC_IP>`）

**约定**：下面「公网」指浏览器或你本机直接访问；「服务器本机」指 SSH 登录后在 ECS 上访问 `127.0.0.1`。

| 用途 | 公网 URL（浏览器 / 本机 curl） | 服务器本机 URL（SSH 里 curl） |
|------|-------------------------------|------------------------------|
| 后端根 + 健康检查 | `http://<ECS_PUBLIC_IP>:8000/health` | `http://127.0.0.1:8000/health` |
| 后端 Swagger 文档 | `http://<ECS_PUBLIC_IP>:8000/docs` | `http://127.0.0.1:8000/docs` |
| 前端首页 | `http://<ECS_PUBLIC_IP>:3000/` | `http://127.0.0.1:3000/` |
| 素材页 | `http://<ECS_PUBLIC_IP>:3000/materials` | `http://127.0.0.1:3000/materials` |
| 素材上传页 | `http://<ECS_PUBLIC_IP>:3000/materials/upload` | `http://127.0.0.1:3000/materials/upload` |
| 接口联调页 | `http://<ECS_PUBLIC_IP>:3000/tester` | `http://127.0.0.1:3000/tester` |
| 工作流列表 | `http://<ECS_PUBLIC_IP>:3000/workflows` | `http://127.0.0.1:3000/workflows` |
| 工作流详情（把 `{id}` 换成 UUID） | `http://<ECS_PUBLIC_IP>:3000/workflows/{id}` | `http://127.0.0.1:3000/workflows/{id}` |

**后端 API 路径结构（均在 `:8000` 下，与前端域名无关）**：

- 认证：`POST /auth/login`，`GET /auth/me`
- 素材：`GET/POST /materials`，`GET /materials/{id}`，`DELETE /materials/{id}`，`POST /materials/{id}/restore`，`DELETE /materials/{id}/permanent?confirm=...`
- 上传：`POST /uploads/init`，`POST /uploads/{id}/chunks/{n}`，`GET /uploads/{id}/chunks`，`POST /uploads/{id}/complete`，`POST /uploads/{id}/ingest`
- 标签：`GET /tags`，`GET /tags/categories`，`POST /tags/apply`，等
- NAS 任务：`GET /nas-jobs/poll`（需 NAS Token 头），`GET /nas-jobs/{job_id}`（管理员 Bearer）

**拼完整 API 地址示例**：`http://<ECS_PUBLIC_IP>:8000` + `/materials` → `http://<ECS_PUBLIC_IP>:8000/materials`

**内网下载机（NAS 上跑 download_server 时，默认文档里的示例）**：`http://<FILE_HTTP_HOST>:9001/download?ticket=...`（IP/端口以你实际 `LAN_DOWNLOAD` 配置为准，与 ECS 公网 IP 不同。）
