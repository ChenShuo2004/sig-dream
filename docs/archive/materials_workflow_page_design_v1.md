# 素材库与工作流页面设计说明 V1

版本：V1.0  
适用系统：轻量内容流程平台  
模块：素材库 / 工作流 / 任务中心  
核心原则：素材资产统一管理，工作流按需调用，任务按包执行。

---

# 一、结论

素材库不要按传统“文件夹 → 文件”的方式设计。

本系统的素材不是普通网盘文件，而是内容生产资产。  
一个素材可以同时属于多个标签、多个集合、多个项目、多个任务。

正确设计是：

```text
素材库 = 资产管理与检索中心
工作流 = 生产流程编排中心
任务中心 = 具体任务执行中心
```

虚拟集合、项目素材包、任务素材包都是素材引用关系，不是真实文件夹。

删除集合、移出素材、删除任务素材包，都不会删除真实 NAS 文件。

---

# 二、核心概念

## 1. 素材资产

素材资产是系统里的真实素材记录。

包括：

```text
视频
图片
音频
文档
```

真实文件存 NAS。  
数据库只存元数据、标签、路径、权限、日志、使用记录。

---

## 2. 虚拟集合

虚拟集合不是文件夹，而是素材引用关系。

它类似：

```text
收藏夹
主题素材包
临时素材组
团队常用素材包
```

示例：

```text
理想L9充电口素材集合
乱停车争议素材集合
车机壁纸素材集合
理想车主共鸣素材集合
```

删除虚拟集合：

```text
只删除集合本身和引用关系
不删除真实素材
不删除 NAS 文件
```

---

## 3. 项目素材包

项目素材包对应一个长期项目或账号方向。

示例：

```text
理想车机壁纸项目素材包
任务大师项目素材包
理想车主共鸣账号素材包
新能源汽车用车痛点项目素材包
```

作用：

```text
长期沉淀某个项目可复用素材
方便工作流直接调用
方便团队按项目组织素材
```

删除项目素材包：

```text
只解除项目与素材的引用关系
不删除真实素材
```

---

## 4. 任务素材包

任务素材包对应一次具体制作任务。

示例：

```text
4月27日乱停车图文任务素材包
理想HUD雪地模式视频任务素材包
车机壁纸教程第3条视频素材包
```

作用：

```text
让制作人员只看到本次任务需要的素材
减少翻素材库时间
提高交付效率
```

删除任务素材包：

```text
只删除任务素材引用关系
不删除真实素材
```

# 三、素材库、工作流、任务中心的分工

## 1. 素材库负责什么

素材库负责长期资产管理。

包括：

```text
上传素材
搜索素材
标签筛选
素材预览
素材下载
素材集合管理
项目素材包管理
标签管理
回收站
操作日志
素材使用记录
```

素材库回答的问题：

```text
这个素材是什么？
在哪里？
能不能用？
怎么找到？
被谁用过？
属于哪些集合？
```

---

## 2. 工作流负责什么

工作流负责生产流程编排。

包括：

```text
素材检索节点
素材集合输入节点
项目素材包输入节点
选题生成节点
文案生成节点
人工审核节点
任务派发节点
任务素材包创建节点
```

工作流回答的问题：

```text
当前这个生产流程需要哪些素材？
这些素材如何进入选题、文案、审核、任务派发？
```

---

## 3. 任务中心负责什么

任务中心负责具体任务执行。

包括：

```text
待制作任务
任务素材包
制作人员下载素材
提交成片
任务状态流转
任务完成记录
```

任务中心回答的问题：

```text
这次任务要做什么？
需要哪些素材？
谁负责？
做到哪一步？
```

## 5. 标签分类

标签分类下拉项不要带“标签”两个字。

正确显示：

```text
内容对象
素材形态
用途
场景
内容主题
状态
```

不要显示为：

```text
内容对象标签
素材形态标签
用途标签
场景标签
内容主题标签
状态标签
```

原因：

```text
左侧标题已经是“标签分类”
下拉项继续带“标签”两个字，会重复、啰嗦、视觉负担重
```

# 九、上传设计

上传不建议做成一个孤立的大页面。

推荐：

```text

→ 打开上传抽屉 / 上传弹窗
```

上传抽屉包含：

```text

批量文件列表

断点续传状态
重复文件提醒

```

---

## 1. 批量上传规则

```text
批量上传前先选择一组默认标签
所有文件继承默认标签
上传后可以逐个修改
```

---

## 2. 标签必填规则

上传时强制：

```text
素材形态必填

```

建议填写：

```text

```

```text

```

无法判断：

```text
进入未整理

```

# 十三、数据库关系建议

## 1. 素材集合表

```sql
CREATE TABLE asset_collections (
    id UUID PRIMARY KEY,
    name TEXT NOT NULL,
    collection_type TEXT NOT NULL,
    description TEXT,
    owner_id UUID,
    visibility TEXT DEFAULT 'private',
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    deleted_at TIMESTAMP
);
```

collection_type：

```text
personal_collection
team_collection
project_package
task_package
```

visibility：

```text
private
team
public
```

---

## 2. 集合素材关联表

```sql
CREATE TABLE asset_collection_items (
    id UUID PRIMARY KEY,
    collection_id UUID REFERENCES asset_collections(id),
    asset_id UUID REFERENCES material_assets(id),
    added_by UUID,
    sort_order INTEGER DEFAULT 0,
    note TEXT,
    created_at TIMESTAMP DEFAULT NOW(),
    UNIQUE(collection_id, asset_id)
);
```

或者：

# 十四、页面交互用词规范

## 1. 禁用词

不要使用：

```text
文件夹
移动到文件夹
从文件夹删除
文件夹内文件
```

原因：

```text
容易让用户误解为真实 NAS 文件目录操作
```

---

## 2. 推荐用词

使用：

```text
素材集合
项目素材包
任务素材包
加入到...
从集合移出
从素材包移出
引用素材
解除引用
```

---

## 3. 删除表达

删除集合：

```text
删除集合不会删除真实素材，只会删除引用关系。
```

从集合移出：

```text
从集合移出不会删除真实素材。
```

删除素材：

```text
删除素材会进入回收站，需要管理员永久删除。
```

# 十六、给 Cursor 的完整改造指令

```text
请重构素材库页面的信息架构和 UI。

目标：
素材库不是传统文件夹系统，而是素材资产管理系统。

   - 缩略图
   - 标题 / 原始文件名
   - 文件类型
   - 状态
   - 核心标签 3～5 个
   - 下载次数
   - 任务使用次数
   - 上传人
   - 上传时间
4. 支持勾选素材。
5. 勾选后显示底部批量操作条：
   - 已选择 N 个素材
   - 批量下载
   - 加入集合
   - 加入项目素材包
   - 加入任务素材包

1. 选择文件
2. 批量文件列表
3. 选择默认标签
4. 逐个文件修改标签

2. 批量下载放在底部批量操作条。

1. 素材集合、项目素材包、任务素材包都是素材引用关系。

4. 任务素材包输入节点

任务中心负责具体任务执行。
任务详情页显示任务素材包。
任务素材包只是引用素材，不复制文件，不删除文件。

1. JWT token

4. 原始状态字符串输入框

素材库页面使用真实用户控件。
```
