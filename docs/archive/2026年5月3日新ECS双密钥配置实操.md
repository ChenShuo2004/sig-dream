# 新 ECS 双密钥配置实操（命令版）

**密钥 A**：你电脑 → ECS（登录、`deploy-oneclick.ps1` 里 `ssh` 到 ECS）。  
**密钥 B**：ECS → GitHub（`git clone` / `git pull`，仓库 **Deploy keys**）。  
**（补充）本机 → GitHub**：你电脑 → GitHub（本机 **`git push`** / IDE 推送，账号 **SSH keys**），见 **§7**。

---

## 0. 先改这两个值（全文仅此一处要手改）

| 变量含义 | 示例 | 你改成 |
|----------|------|--------|
| ECS 公网 IP | `<ECS_PUBLIC_IP>` | 你的 IP |
| GitHub 仓库（SSH） | `git@github.com:ChenShuo2004/sig-dream.git` | 你的仓库 |

下面命令里已写死示例 IP / 仓库；若不同，请全文替换。

## 1. 密钥 A：Windows PowerShell（在你自己电脑上执行）

**1.1 生成密钥（空口令；不要用 `-N ""`，会报 Too many arguments）**

```powershell
ssh-keygen -t ed25519 -f "$env:USERPROFILE\.ssh\id_ed25519_ecs" -q -N '""' -C "admin-to-ecs-47"
Get-Content "$env:USERPROFILE\.ssh\id_ed25519_ecs.pub"

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIGf9sl1yvBLOlwOWWPufr0b20LT95K2pU3U7EQ++u1X8 admin-to-ecs-47
```

复制输出的**一整行**公钥（`ssh-ed25519 AAAA...`）。

**1.2 公钥写入 ECS（二选一）**

*已能用密码 `ssh root@<ECS_PUBLIC_IP>` 时，在本机一条命令：*

```powershell
Get-Content "$env:USERPROFILE\.ssh\id_ed25519_ecs.pub" | ssh root@<ECS_PUBLIC_IP> "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"
```

*或在阿里云 VNC/Workbench 登录 ECS 后执行：*

```bash
mkdir -p ~/.ssh && chmod 700 ~/.ssh
nano ~/.ssh/authorized_keys
# 粘贴 1.1 那一整行公钥，保存退出
chmod 600 ~/.ssh/authorized_keys
```


**1.4（可选）想继续打 `ssh root@<ECS_PUBLIC_IP>` 

*PowerShell 一条写入（**整段复制执行一次**；若 `config` 里已有相同 `Host`，先删掉旧块再执行，避免重复）：*

```powershell
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.ssh" | Out-Null
@'
Host <ECS_PUBLIC_IP>
  User root
  IdentityFile ~/.ssh/id_ed25519_ecs
  IdentitiesOnly yes
'@ | Add-Content -Path "$env:USERPROFILE\.ssh\config" -Encoding utf8
```

然后：

```powershell
ssh root@<ECS_PUBLIC_IP>
```

## 2. 密钥 B：在 ECS 上执行（`ssh` 登录进 ECS 后，bash）

**2.1 生成专用密钥（不要复用密钥 A）**
 
 ECS服务器运行：
```bash
mkdir -p ~/.ssh && chmod 700 ~/.ssh
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_github_deploy -N "" -C "ecs-readonly-deploy-key"
cat ~/.ssh/id_ed25519_github_deploy.pub
```

复制 `cat` 输出的**一整行**。

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIF59c0SGUfV+UyyXMF4naqcJVc90mNqvTr8K/BWsHK5R ecs-readonly-deploy-key
**2.2 浏览器操作（无 CLI）**

打开：`https://github.com/ChenShuo2004/sig-dream/settings/keys`  
**Add deploy key** → Title 随意 → Key 粘贴上一步 → 勾选 **Allow read access** → **Add key**。

**2.3 ECS 上固定用这把钥连 GitHub**

```bash
cat >> ~/.ssh/config << 'EOF'
Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519_github_deploy
  IdentitiesOnly yes
EOF
chmod 600 ~/.ssh/config
```

**2.4 验证**

```bash
ssh -T git@github.com
rm -rf /tmp/gh-clone-test
git clone git@github.com:ChenShuo2004/sig-dream.git /tmp/gh-clone-test
test -f /tmp/gh-clone-test/deploy.sh && echo OK
```

## 3. 一键部署与 A / B / 本机 GitHub 的关系（一句话）

- 本机 `deploy-oneclick.ps1` 里 **`git push origin …`** 在 **你的 Windows** 上执行，用的是 **本机 `~/.ssh` → GitHub 用户 SSH Keys**（见 **§7**），与 ECS 上的 **密钥 B** 无关。  
- 脚本在 **ECS** 上若自动 **`git clone` / `git pull`**，走 **密钥 B**（**2.2 + 2.3**）。  
- 本机 **`ssh root@ECS_IP`** 仍只依赖 **密钥 A**。

---

## 4. 对照表

| | 密钥 A | 密钥 B | 本机 → GitHub（§7） |
|--|--------|--------|---------------------|
| 生成于 | 你的 Windows | ECS | 你的 Windows |
| 私钥（示例路径） | `%USERPROFILE%\.ssh\id_ed25519_ecs` | `/root/.ssh/id_ed25519_github_deploy` | `%USERPROFILE%\.ssh\id_ed25519_github_win`（文件名可自定） |
| 公钥加到 | ECS `/root/.ssh/authorized_keys` | GitHub 仓库 **Deploy keys** | GitHub 账号 **SSH and GPG keys**（用户级） |
| 典型用途 | `ssh root@ECS` | ECS 上 `git clone` / `pull` | 本机 `git push`、IDE 推送 |

---

## 5. 仍要密码 / 仍 clone 失败（各一行）

- **本机连 ECS 仍要密码**：你用的是自定义文件名，请用 **1.3** 的 **`-i`**，或 **1.4** 的 **config**；不要只打 `ssh root@IP`（除非私钥叫默认名且已对上）。  
- **本机 `git push` 报 `publickey`、ECS 上 `ssh -T git@github.com` 却正常**：按 **§7** 配置 **Windows → GitHub 用户 SSH Keys**（与 ECS 上 **Deploy key** 不是同一处）。  
- **ECS 上公钥无效**：`authorized_keys` 必须**一行一条**；`chmod 700 ~/.ssh`；`chmod 600 ~/.ssh/authorized_keys`。  
- **macOS/Linux 本机生成**：`ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_ecs -q -N "" -C "admin-to-ecs-47"`  

---

## 6. 安全

私钥不要发聊天、不要进 Git。Deploy Key 只读即可。

---

## 7. 本机 Windows：配置 SSH 公钥到 GitHub（`git push` / 图形界面推送）

**场景**：本机执行 `deploy-oneclick.ps1` 或终端里 `git push`，报错 **`Permission denied (publickey)`**；但在 **ECS** 上 `ssh -T git@github.com` 正常——说明 **ECS 的密钥 B 没问题**，缺的是 **Windows 本机** 上的一把 **账号级** GitHub 公钥（若在 GitHub 上误删了对应公钥，本机 push 也会同样失败）。

**与密钥 B 的区别**：**Deploy key** 挂在**仓库**上，私钥在 **ECS**；**本机 push** 需要把公钥加到 **你的 GitHub 用户**（[SSH and GPG keys](https://github.com/settings/keys)），私钥留在 **Windows**。

### 7.1 生成专用密钥（勿与密钥 A 共用同一文件）

在 **本机 PowerShell** 执行（注释 `-C` 可改成自己的机器备注）：

```powershell
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.ssh" | Out-Null
ssh-keygen -t ed25519 -f "$env:USERPROFILE\.ssh\id_ed25519_github_win" -q -N '""' -C "windows-to-github-push"
Get-Content "$env:USERPROFILE\.ssh\id_ed25519_github_win.pub"

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIGxJtHAs3BXt9UiumLAdMuWw5Xj3uFNRhg0LRp41iaX3 windows-to-github-push
```

复制输出的 **一整行** `ssh-ed25519 AAAA...`。

### 7.2 浏览器：把公钥加到 GitHub 账号

1. 登录 GitHub → **Settings** → **SSH and GPG keys**：`https://github.com/settings/keys`  
2. **New SSH key** → Title 随意（如 `Win10 开发机`）→ Key 粘贴 **7.1 整行公钥** → **Add SSH key**。

（不要贴到仓库的 **Deploy keys** 里替代本步骤；Deploy key 是给 ECS 拉代码用的另一套。）

### 7.3 本机指定：连 `github.com` 时用这把私钥

避免与密钥 A、其它默认 `id_ed25519` 混淆，建议为 `github.com` 单独写 **`~/.ssh/config`**（**整段复制执行一次**；若已有 `Host github.com` 块，先编辑合并，避免重复）：

```powershell
@'
Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519_github_win
  IdentitiesOnly yes
'@ | Add-Content -Path "$env:USERPROFILE\.ssh\config" -Encoding utf8
```

### 7.4 验证

```powershell
ssh -T git@github.com
```

期望看到类似：`Hi <你的用户名>! You've successfully authenticated, but GitHub does not provide shell access.`

然后在仓库目录执行一次：

```powershell
git fetch origin
```

无公钥错误即可。再跑 **`deploy-oneclick.ps1`** 或 **`git push origin main`**。

### 7.5（可选）`ssh-agent` 与本机多把密钥

若仍提示公钥不对，可确认 **GitHub 网页上该公钥仍存在**（误删后需重新 **7.1 生成新钥对** 或恢复备份，并更新 **7.2**）。  

也可在本机加载私钥（需 **OpenSSH Authentication Agent** 服务已启动）：

```powershell
Get-Service ssh-agent | Set-Service -StartupType Manual
Start-Service ssh-agent
ssh-add "$env:USERPROFILE\.ssh\id_ed25519_github_win"
ssh -T git@github.com
```

与 **§1** 的 **`IdentitiesOnly yes` + `IdentityFile`** 二选一或并用均可；**config 里为 `github.com` 指定 `IdentityFile`** 通常已足够。
