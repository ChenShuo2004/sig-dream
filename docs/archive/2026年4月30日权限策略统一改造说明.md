# 2026-04-30 权限策略统一改造说明

## 目标

- 保持以下页面前端继续使用 `role === super_admin` 直接拦截：
  - 系统设置
  - 同步异常
  - 业务验收测试
- 上述页面对应后端接口同步收敛为仅超级管理员可访问（操作日志除外，改为 `log.view`）。
- 其他业务模块按“权限点优先”改造，避免仅靠角色硬编码。

## 本次改造内容

### 1) 登录态补齐权限点

- 后端 `auth/me` 新增 `permissions` 字段返回当前用户有效权限集合。
- 前端登录后将 `permissions` 写入本地会话（`auth_session_v1`），供各页面做按钮/操作级控制。

涉及文件：

- `backend/app/schemas/auth.py`
- `backend/app/api/routes/auth.py`
- `frontend/lib/auth.ts`
- `frontend/app/login/page.tsx`

### 2) 三个超管页面：后端只允许 super_admin

- 同步异常相关接口收敛为仅 `super_admin`：
  - `GET /nas-jobs/{job_id}`
  - `GET /nas-jobs/sync/deadletters`
  - `POST /nas-jobs/sync/{sync_operation_id}/action`
  - `POST /nas-jobs/sync/reconcile`
  - `GET /nas-jobs/sync/maintenance-status`
  - `POST /nas-jobs/sync/reconcile-with-maintenance`
  - `POST /nas-jobs/sync/maintenance-announcement/publish`
  - `POST /nas-jobs/sync/maintenance-announcement/withdraw`

涉及文件：

- `backend/app/api/routes/nas_jobs.py`

### 3) 其他模块改为权限点驱动（前端）

- 素材库页面：
  - 下载：`asset.download`
  - 批量下载：`asset.batch_download`
  - 移入回收站：`asset.delete_own` / `asset.delete_all`
  - 使用记录：`log.view`
- 回收站页面：
  - 是否可管理全量回收站：`asset.restore_all`
  - 是否可彻底删除（单个/批量）：`asset.permanent_delete`
- 标签管理页面：
  - 创建/申请按钮逻辑：`tag.create`
  - 审核入口：`tag.review`
  - 停用/启用：`tag.disable`
  - 合并：`tag.merge`
  - 删除/彻底删除：`tag.delete`
- 标签审核页：
  - 页面访问条件改为 `tag.review`

涉及文件：

- `frontend/app/materials/page.tsx`
- `frontend/app/trash/page.tsx`
- `frontend/app/tags/page.tsx`
- `frontend/app/tag-requests/page.tsx`

### 4) 其他模块改为权限点驱动（后端补齐）

- 操作日志接口由 `super_admin` 收敛改为权限校验：
  - `log.view`
- 素材下载缓存直链（Bearer 模式）由角色校验改为权限校验：
  - `asset.download`
- 素材彻底删除接口由角色校验改为权限校验：
  - `asset.permanent_delete`

涉及文件：

- `backend/app/api/routes/operation_logs.py`
- `backend/app/api/routes/materials.py`

## 验证建议

- 权限点去歧义：
  - 已废弃 `trash.permanent_delete`、`trash.view`、`trash.restore`。
  - 回收站能力统一使用素材权限表达：
    - `asset.delete_own`：移入自己上传素材到回收站
    - `asset.delete_all`：移入所有素材到回收站
    - `asset.restore_own`：回收站恢复自己上传的素材
    - `asset.restore_all`：回收站恢复所有素材
    - `asset.permanent_delete`：回收站永久删除素材
- 使用系统设置为同一账号分别勾选/取消以下权限，验证前端按钮和后端返回是否一致：
  - `asset.download`
  - `asset.batch_download`
  - `asset.delete_own` / `asset.delete_all`
  - `asset.restore_own` / `asset.restore_all`
  - `asset.permanent_delete`
  - `tag.create`
  - `tag.review`
  - `tag.disable`
  - `tag.merge`
  - `tag.delete`
  - `log.view`
- 重点回归：
  - 无 `log.view` 权限用户访问操作日志接口应返回 403。
  - 非超管访问同步异常接口应返回 403。
  - 非 `tag.review` 用户访问标签审核页应显示无权限。
  - 非 `asset.permanent_delete` 用户不可见/不可执行回收站彻底删除操作。
