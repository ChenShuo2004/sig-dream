# 2026年4月28日素材库页面闭环分阶段实施

## 1. 目标

把 `materials` 页面从“可演示”提升到“可业务使用”，形成可验收闭环：

- 能筛选（文件夹、标签分类、标签组合）
- 能查询与查看详情
- 能下载与记录使用
- 能回收站管理
- 能与标签管理流程联动

---

## 2. 分阶段实施总览

### 阶段1：筛选闭环（本次先落地）

- [x] 左侧文件夹点击联动（全部/未分类/回收站）
- [x] 左侧标签分类可切换
- [x] 标签多选筛选（AND，映射 `tag_ids_all`）
- [x] 查询区展示已选标签与一键清空

验收标准：

- 选择任意标签后点击查询，接口参数包含 `tag_ids_all` 多值
- 选择“回收站”时自动切到 `status=trashed`
- 选择“未分类”时能过滤出无标签素材

### 阶段2：列表与详情闭环

- [x] 列表字段整理（标题/状态/上传者/时间/下载数）
- [x] 详情区可查看派生信息（duration/thumbnail/preview）
- [x] 空态、错误态、加载态统一
- [x] URL 参数持久化筛选条件（刷新不丢）

验收标准：

- `F5` 前端可查可看稳定通过

### 阶段3：下载与使用记录闭环

- [x] 生成下载链接流程可视化（job 轮询状态）
- [x] 成功下载后前端提示 download_count 变化
- [x] 接口返回 `source` 可读展示（`download_cache` / `download_ticket`）
- [x] member 权限失败提示明确

验收标准：

- `G3/G4/G5` 可在页面端复现并通过

### 阶段4：回收站闭环

- [x] 拆分独立回收站页 `trash`（可选）或当前页完整回收站模式
- [x] 软删/恢复/永久删操作链路统一提示
- [x] 永久删除二次确认强化（风险提示）
- [x] 角色可见性一致（member 隐藏高危按钮）

验收标准：

- `H`、`I` 相关验收项前端端到端通过

### 阶段5：标签管理联动闭环

- [x] 标签管理页 `tags`
- [x] 标签申请/审核页 `tag-requests`
- [x] 停用、合并在前端可操作
- [x] 素材页标签状态联动（active/pending/inactive）

验收标准：

- `C` 相关能力可在前端完整演示
