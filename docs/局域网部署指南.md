# sig-dream 局域网版本部署指南

适合在办公室或工作室内部直接部署：**不需要公网云服务器**，一台局域网主机（Windows / macOS / Linux 均可）即可同时承载工作台、无限画布与团队素材库，素材原件全部留在内网，同事通过浏览器或桌面客户端以局域网速度访问。

---

## 架构一览

```text
办公室成员（浏览器 / Windows·macOS·Linux 桌面客户端）
        │  访问 http://<局域网主机IP>:3000
        ▼
局域网主机（PostgreSQL + FastAPI :8000 + Next.js 工作台 :3000）
        │  大文件直传（可选，支持同机或独立 NAS 文件机）
        ▼
文件机 nas-client（:9001，负责原件存储、FFmpeg 缩略图与 H.264 预览）
```

---

## 一、环境准备

在局域网主机上安装：

- **Python 3.11+**
- **Node.js 20+**
- **PostgreSQL 14+**（创建空库，例如 `light_content`）
- **FFmpeg & FFprobe**（已加入系统 `PATH`，用于素材缩略图与预览视频生成）

假设局域网主机的内网固定 IP 为 `192.168.1.100`（请替换为实际 IP，并在路由器中为该主机绑定静态 IP）。

---

## 二、启动后端与数据库

```bash
git clone https://github.com/ChenShuo2004/sig-dream.git
cd sig-dream/backend

python3 -m venv .venv
# macOS / Linux:
.venv/bin/pip install -r requirements.txt
cp .env.example .env
# Windows PowerShell:
# .\.venv\Scripts\pip install -r requirements.txt
# Copy-Item .env.example .env
```

编辑 `backend/.env`，至少修改以下配置：

```env
DATABASE_URL=postgresql+psycopg://postgres:你的密码@127.0.0.1:5432/light_content
TOKEN_SECRET=替换为随机长密钥
NAS_CLIENT_TOKEN=替换为随机长密钥
DOWNLOAD_TICKET_SECRET=替换为随机长密钥

# 局域网文件机直传地址（若文件机与主机同机，填本机局域网 IP）
LAN_DOWNLOAD_BASE_URL=http://192.168.1.100:9001
LAN_UPLOAD_BASE_URL=http://192.168.1.100:9001
```

初始化数据库并监听局域网网卡：

```bash
# macOS / Linux
.venv/bin/alembic upgrade head
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000

# Windows PowerShell
.\.venv\Scripts\alembic upgrade head
.\.venv\Scripts\uvicorn app.main:app --host 0.0.0.0 --port 8000
```

浏览器打开 `http://192.168.1.100:8000/health` 返回 `{"status":"ok"}` 即表示后端就绪。

---

## 三、启动前端工作台与 sig画布

仓库已包含构建好的 `sig画布` 前端产物；如需从源码重新构建画布：

```bash
cd canvas-app/web
npm ci --legacy-peer-deps
npm run build
```

启动 Next.js 工作台并对外网段开放 `3000` 端口：

```bash
cd frontend
npm ci
npm run build
npx next start -H 0.0.0.0 -p 3000
```

> 同事在办公室任意电脑打开 **`http://192.168.1.100:3000`** 即可访问。前端内置 `/api-proxy` 自动转发到同机 `127.0.0.1:8000`，无需额外配置 Nginx。

首次登录初始账号为 `admin`，密码 `admin123`。登录后请立即在 **系统设置 → 用户** 中修改密码，并为团队成员创建账号与角色权限。

---

## 四、启用局域网文件机（素材原件存储与预览转码）

如果不启动文件机，平台仍可登录、使用 `sig画布`、提示词库与工作室；启用文件机后即可支持团队大文件直传、自动生成缩略图与 H.264 预览。

在存放素材的局域网机器（可与主机同机，也可单独接 NAS）上：

```powershell
cd nas-client
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
Copy-Item nas-client-token.txt.example nas-client-token.txt   # 填入与 backend/.env 相同的 NAS_CLIENT_TOKEN
Copy-Item ecs-api-url.txt.example ecs-api-url.txt             # 填入 http://192.168.1.100:8000
```

回到仓库根目录运行 `start-nas-direct-services.bat`（Windows）即可启动局域网下载服务（默认 `9001` 端口）与缩略图/预览转码 Worker。

---

## 五、连接桌面端（Windows / macOS / Linux）

桌面客户端支持在团队局域网中浏览素材库与集合、打开 `sig画布`，并将素材**直接拖进剪映、Premiere、DaVinci 等剪辑软件**。

1. 前往 [Releases](https://github.com/ChenShuo2004/sig-dream/releases/latest) 下载对应系统的安装包（Windows `.exe` / `.zip`，macOS Apple Silicon / Intel `.dmg`，Linux `.AppImage` / `.deb`）。
2. 首次打开客户端时，在登录页的 **服务器地址** 中填写局域网工作台地址，例如：
   ```text
   http://192.168.1.100:3000
   ```
3. 保存后使用团队账号登录即可。客户端本地缓存目录与 NAS 映射盘符可在客户端内的「桌面设置」中调整。

---

## 六、防火墙放行检查

如果其他同事无法访问 `http://192.168.1.100:3000`，请在局域网主机的系统防火墙中放行以下入站 TCP 端口：

- `3000`：工作台与 sig画布（必需）
- `8000`：FastAPI 后端接口（供文件机与桌面端直连时放行）
- `9001`：局域网文件机上传与下载服务（启用文件机时放行）
- `7865` / `7866`：Seed-VC 与 SVS 本地 GPU 翻唱服务（可选）
