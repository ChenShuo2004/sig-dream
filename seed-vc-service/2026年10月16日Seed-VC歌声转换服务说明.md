# Seed-VC 歌声转换服务说明

零样本歌声 / 语音音色转换，**不训练 RVC**。干声（Demucs `vocalsKey`）+ 目标参考声 → Seed-VC，结果写入句级 `audioKey`，可与原声 A/B 对比。

## 端口与地址

| 环境 | URL |
|------|-----|
| 本机调试 | `http://127.0.0.1:7865` |
| 办公室 GPU（优先） | `http://192.168.1.88:7865` |
| 备选网段 | `http://192.168.2.88:7865` |

文件机环境变量：

- `LAN_SEEDVC_URL_1`（默认 `http://192.168.1.88:7865`）
- `LAN_SEEDVC_URL_2`（默认 `http://192.168.2.88:7865`）

## 一键启动（可复制到 88）

1. 把整个 `seed-vc-service` 目录拷到 GPU 机（或本机），例如 `D:\seed-vc-service`。
2. **不要**再装 `upstream\requirements.txt`（含 Gradio / nightly torch，会与 FastAPI 冲突）。
3. 双击 `一键启动.bat`：用清华镜像装 `requirements-infer.txt`，torch 从 `pytorch.org` 拉 **2.4.0+cu121**。
4. 首次成功后会写 `.venv\seedvc_deps_ok.txt`，以后直接启动；要重装就删该文件或整个 `.venv`。
5. `curl http://127.0.0.1:7865/health` 看到 `ok: true` 即可。

建议 Python **3.10** + CUDA 12.x。若 cu121 轮子装不上，bat 会回退 CPU torch（歌声推理会很慢）。

## API

- `GET /health`
- `POST /convert` multipart：
  - `source`：要保留旋律/内容的干声
  - `reference`：目标音色（约 1～30 秒）
  - `f0_condition=1`：歌声转换（默认）
  - `diffusion_steps=40`：歌声建议 30～50
  - `auto_f0_adjust=0`：歌声一般关闭
  - `pitch_shift`：半音移调，默认 0

## 平台链路

画布 / 替换工作室 → ECS `POST /canvas-lan/voice-convert` → 文件机 `lan_voice_convert` → 本服务 `/convert`。
