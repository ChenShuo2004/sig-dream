请在素材库下载功能中增加“选择本地目录保存”能力。

一、功能入口

在素材详情抽屉的“下载”按钮点击后，弹出下载方式选择：

1. 浏览器默认下载
2. 选择本地目录保存

如果当前浏览器不支持 showDirectoryPicker，则隐藏“选择本地目录保存”。

二、下载选路保持不变

仍然先走现有逻辑：

1. 请求 ECS 生成 download ticket
2. 前端探测 LAN
3. LAN 可用则使用 LAN downloadUrl
4. LAN 不可用则探测 WAN
5. WAN 可用则使用 WAN downloadUrl
6. 都不可用则使用 ECS fallback

三、浏览器默认下载

使用：

window.location.href = downloadUrl

或创建 a 标签触发下载。

四、选择本地目录保存

使用 File System Access API：

1. showDirectoryPicker 让用户选择本地目录
2. 根据素材文件名创建文件
3. fetch(downloadUrl) 获取文件流
4. 使用 writable stream 写入本地文件
5. 显示下载进度
6. 下载完成后提示成功

五、CORS 要求

如果使用 fetch(downloadUrl)，LAN/WAN 文件机需要允许前端跨域读取：

- Access-Control-Allow-Origin
- Access-Control-Allow-Methods: GET, OPTIONS
- Access-Control-Allow-Headers

否则“选择本地目录保存”无法读取文件流。

六、文件名冲突

V1 采用自动重命名策略：

demo.mp4
demo (1).mp4
demo (2).mp4

七、移动端处理

移动端默认只显示“浏览器默认下载”。
不要强行做目录选择。

八、操作日志

无论哪种下载方式，都要记录下载日志：

- 用户
- 素材 ID
- 下载方式：browser_default / choose_directory
- 传输路径：lan_direct / wan_direct / ecs_fallback
- 成功 / 失败
- 文件大小
- 时间
